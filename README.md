# Atalaya Launcher

Aquí se descarga el launcher de **Atalaya**, la serie hardcore de Minecraft 26.2.

**Descárgalo aquí:** [Launcher-Setup.exe](https://github.com/SiologoDr/atalaya-launcher/releases/latest/download/Launcher-Setup.exe) (siempre la última versión).

Se actualiza solo: cuando sale algo nuevo del launcher o de los mods, lo baja, revisa su huella y lo instala.
Si quieres comprobar que el instalador es el original, cada versión trae su huella SHA-256 (`Launcher-Setup.exe.sha256`).

Aquí no hay código, solo las descargas.
