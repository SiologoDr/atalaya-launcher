# Atalaya Launcher

Descargas del launcher de **Atalaya**, una serie hardcore para Minecraft 26.2.

- **Descarga el instalador:** [Launcher-Setup.exe](https://github.com/SiologoDr/atalaya-launcher/releases/latest/download/Launcher-Setup.exe) (siempre la última versión).
- Junto a cada instalador está su huella SHA-256 (`Launcher-Setup.exe.sha256`) para comprobar que no se ha modificado.
- El launcher se actualiza solo: cuando sale una versión nueva del launcher o de los mods, la descarga, comprueba su huella y la instala.

Aquí no hay código: solo lo que el launcher descarga.
